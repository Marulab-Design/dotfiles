# CachyOS Hyprland dotfiles

A Hyprland Lua configuration for an HP ZBook Firefly 15 G8 (32 GB RAM, NVIDIA T500), with Noctalia v5, Kitty and Waybar as the default bar. Start with the **[installation and troubleshooting guide](docs/INSTALL.md)**. Noctalia provides the launcher, notifications, wallpaper and lock screen; its bar is disabled so Waybar is the only panel.

The configuration uses automatic monitor detection and does not force a GPU or VA-API driver. Set display scaling and wallpaper for your machine after installation. Some personal shortcuts reference optional apps; see the guide.
